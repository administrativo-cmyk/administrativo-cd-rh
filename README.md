# Administrativo CD

Sistema web administrativo de RH e operação dos centros de distribuição.

## Módulos em desenvolvimento

- Chamada Diária
- Banco de Horas
- Quadro Atual
- Gestão de usuários
- Demais módulos de RH

## Stack

- Next.js
- React
- TypeScript
- Supabase
- PostgreSQL

## Comandos

```bash
pnpm install
pnpm dev
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```
